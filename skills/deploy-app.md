# Deploy App

Deploy applications to production environments.

## Usage
```
/deploy-app "my-react-app to Vercel"
/deploy-app "backend API to AWS"
```

## Workflow
1. Build application
2. Configure environment
3. Deploy to target
4. Run health checks
5. Configure monitoring

## Tools
- Vercel CLI
- AWS CLI
- Docker
- Kubernetes
- Cloudflare
