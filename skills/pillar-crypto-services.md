# Pillar 7: Crypto Services

**Category**: crypto
**Description**: Exchange setup, multi-sig wallet management, DeFi integration.

## Capabilities

- **wallet_setup**: Create multi-sig wallets (Gnosis Safe), hardware wallets
- **exchange_setup**: Account setup on major exchanges
- **defi_strategy**: Yield optimization, lending, liquidity provision
- **tax_reporting**: Calculate crypto tax, generate reports

## Supported

- Chains: Ethereum, Solana, Polygon, Avalanche, BSC, Base
- Wallets: Gnosis Safe, Ledger, Trezor, Metamask
- DeFi: Aave, Compound, Uniswap, Curve

## Deliverables

- Wallet setup guide
- Exchange account setup
- DeFi strategy recommendation
- Tax report (8949 format)

## SafetyNet

- Transaction > $10k → compliance check
- Token launch → legal review
- Unknown DeFi protocol → block

## Agents Involved

- Web3 Swarm (primary)
- Compliance Auditor
