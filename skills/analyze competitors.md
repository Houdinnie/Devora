# Analyze Competitors

Research and analyze competitors in the market.

## Usage
```
/analyze-competitors "SaaS CRM market"
/analyze-competitors "AI coding tools"
```

## Workflow
1. Identify competitors
2. Gather company info
3. Analyze products
4. Research pricing
5. Find strengths/weaknesses
6. Generate report

## Tools
- Web research
- Company databases
- Product analysis
- Pricing intelligence
