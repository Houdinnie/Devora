# Employee Manage

HR and employee management.

## Usage
```
/employee-manage add "Jane Doe" --role "Developer"
/employee-manage time-off "jane" --days 5 --dates "2024-02-01"
/employee-manage onboard "new-hire"
```

## Actions
- Manage employee directory
- Process time-off requests
- Schedule reviews
- Track training
- Handle offboarding
