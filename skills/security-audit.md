# Security Audit - AI-Powered Pentesting

Automated security assessment using CAI patterns.

## Usage

```
/security-audit "scan https://example.com for vulnerabilities"
```

## Workflow

1. **Reconnaissance** - Passive info gathering
2. **Vulnerability Discovery** - Active scanning
3. **Exploitation** - Proof of concept generation
4. **Reporting** - CVSS scoring, remediation

## Tools

- Port scanning
- Directory enumeration  
- Payload injection
- JWT exploitation
- API fuzzing

## Guardrails

- Scope limiting
- Rate limiting
- Prompt injection protection

## Models

Supports 300+ models: OpenAI, Anthropic, DeepSeek, Ollama
