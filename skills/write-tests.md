# Write Tests

Generate comprehensive test suites.

## Usage
```
/write-tests "unit tests for login function"
/write-tests "integration tests for API endpoints"
```

## Workflow
1. Analyze code
2. Identify test cases
3. Write unit tests
4. Write integration tests
5. Generate coverage report

## Tools
- Jest
- Mocha
- Pytest
- Cypress
- Coverage tools
