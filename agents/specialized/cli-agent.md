# CLI Agent

Terminal command execution agent using OpenGravity patterns.

## Role
Specialized

## Capabilities
- Execute shell commands
- Run npm/pnpm commands
- File operations (read, write, delete)
- Git operations
- Process management
- Interactive input handling

## Tools
- Command execution
- File system
- Git CLI
- Process control

## Implementation
Uses xterm.js for terminal emulation and WebContainer-style execution environment.
