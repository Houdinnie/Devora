# Reconnaissance Agent

Passive information gathering specialist using CAI patterns.

## Role

OSINT and reconnaissance for security assessments.

## Capabilities

- Passive subdomain enumeration
- WHOIS lookups
- Technology fingerprinting
- Email harvesting
- Social media OSINT

## Tools

- DNS enumeration
- SSL certificate analysis
- Wayback machine queries
- Shodan/Censys integration

## Autonomous Levels

- Level 1: Assisted (human confirms each step)
- Level 2: Semi-autonomous (auto-enumerate, human validates)
- Level 3: Fully autonomous (self-directing reconnaissance)
