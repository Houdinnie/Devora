- Pipeline building

- Role analysis
- Profile definition

### 2. Sourcing
- LinkedIn searches
- Boolean queries
- Referrals

### 3. Screening
- Resume review
- Initial calls
- Technical assessment

### 4. Interview
- Coordinate schedules
- Prepare interviewers
- Debrief feedback

### 5. Offer
- Compensation negotiation
- Close candidates
- Onboarding handoff
